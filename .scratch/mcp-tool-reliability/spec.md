# 双版本 MCP 工具与原生安装可靠性

## 目标

在本机 Blender 5.1.1 和 5.2.2 的隔离配置中真实调用全部 26 个 MCP 工具，检查返回语义及输出文件，保留失败尝试。将问题分为集成、锁定上游、客户端或宿主环境问题；修复本仓库负责的问题并复测。深入复现原生扩展安装阶段的目录重命名 `WinError 5`，使用可观察证据判断来源。

## 验收

- 每个版本均列出 26 个工具、参数、断言、时长与 Passed / Failed / Not Run。
- CLI 工具运行真实 Blender；GUI 截图检查像素；渲染检查实际文件和尺寸。
- 初次失败和重试分别记录，不用重试覆盖失败证据。
- 集成修复包含原失败场景回归；上游问题提供固定提交、最小复现、期望与实际结果。
- 目录问题保留原生安装日志、路径、权限和单变量对照证据；未确认的外部因素明确标为推断。
- 工作环境结束后清理，最新报告和必要截图保留在 `build/latest/`，不修改系统 Blender、用户配置、权限或安全设置。

## 范围

本地实施、测试和报告。外部 issue 由用户后续提交，本次不提交、推送或发布新的安装包。
