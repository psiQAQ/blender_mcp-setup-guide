## 目标与验收

提交客户端与测试维护；在 Blender 5.1.1 / 5.2.2 上通过未修改的官方 Extension、独立 uv 工具环境与真实 stdio 客户端，分别完成三个 GUI 会话和九次缩略图调用。复现的上游缺陷只交付英文 issue 本地文档，并作为已知限制允许发布。
