# 集成发布检查

审查对象包括三平台运行时、固定官方来源、wheel 锁、构建脚本、真实 Blender 测试与发布工作流。

## 检查要点

- 系统、架构和 CPython 3.13 必须匹配平台，原生依赖从私有运行目录加载。
- 显式注册、失败回滚、逆序卸载，清理错误保留，禁止覆盖尚未清理的服务状态。
- 构建仅使用锁定 wheels，保留数据与许可证，最终 ZIP 通过官方 validate。
- 必需 CI 报告匹配平台、提交与最终 ZIP，三平台集合完整，GUI 与最低版本检查不可跳过。
- draft 中逐资产回读；索引验证通过后公开；同版本资产不可替换，旧运行不可回退索引。
- 公共索引由原生环境实际安装并调用 MCP，人工 GUI/客户端验收独立标记。

本地单元检查记录在 integration-validation.md。当前三平台改造的审阅与 CI 证据不同于历史 Windows 单平台审查；正式候选以绑定该提交的 CI 和 Release 报告为依据。
