# Domain docs

本仓库采用 single-context 领域文档布局。

## 探索前读取

- 根目录 `GLOSSARY.md`：读取与当前主题相关的术语。
- 根目录 `docs/adr/`：读取涉及当前工作区域的架构决策。

文件尚不存在时直接继续。`/domain-modeling` 在术语或决策得到明确结论后按需创建文档。

## 文件布局

| 内容 | 路径 |
| --- | --- |
| 领域术语 | `GLOSSARY.md` |
| 架构决策 | `docs/adr/<NNNN>-<slug>.md` |

## 使用领域术语

任务标题、重构建议、假设和测试名称使用词汇表定义的术语。
遇到尚未收录的概念时，先检查现有用语；确有缺口时记录给 `/domain-modeling`。

## 架构决策冲突

建议或实现与现有 ADR 冲突时，明确指出对应 ADR 和重新讨论的理由，交由维护者决定。
